# Code of Conduct

Contributors and maintainers must keep project spaces respectful, constructive,
and free from harassment. Disagreement about code or product direction is
welcome when it focuses on evidence and the work rather than the person.

Unacceptable behavior includes harassment, threats, discriminatory language,
publishing private information, deliberate disruption, and sexualized conduct.
Maintainers may edit or remove contributions and temporarily or permanently ban
participants whose behavior harms the community.

Report conduct concerns privately through the repository maintainer's GitHub
profile. Reports will be reviewed in confidence, with action proportional to
the context and impact.
